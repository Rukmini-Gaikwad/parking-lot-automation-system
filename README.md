# ParkEngine : parking-lot-automation-system

ParkEngine is a Java-based, console-driven parking management system designed using Object-Oriented Programming (OOP) principles and design patterns.
It streamlines vehicle entry and exit, automated parking space allocation, ticket generation, parking fee calculation, and payment simulation. 
The application demonstrates real-world parking operations through a modular, maintainable, and efficient design while strengthening core Java concepts and software development skills.

# Features
- Supports bikes, cars, and trucks.
- Allocates compatible parking spaces across multiple floors.
- Generates parking tickets and tracks entry and exit times.
- Calculates parking charges based on vehicle type and parking duration.
- Supports simulated cash, UPI, and card payments.
- Searches for parked vehicles using their registration numbers.
- Updates parking availability through an observer-based display board.
- Prevents duplicate active parking for the same vehicle.

# Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Java Date and Time API
- Factory, Singleton, Observer, and Strategy design patterns
